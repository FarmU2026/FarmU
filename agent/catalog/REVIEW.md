# Weights review sheet (catalog 2026-10-10.2)

Generated by `agent/catalog/review_sheet.py` from `conditions.json`, `loss_tables.json` and `agents.py`. Do not edit by hand; rerun the script. Every number is a DRAFT. Weight = log-likelihood ratio: +w on `supports`, -w on `refutes`; 1.0 = odds x2.7, 2.0 = x7.4, 3.0 = x20. Status cutoffs: ruled_out < 5%, likely > 60%; how_sure wording: >= 80% pretty sure, >= 55% fairly sure, else not sure. A repeat of the same (condition, key, direction) counts once. Final log-odds clamp at +-8.

Column key: **dir** = usual direction by key name (heuristic): `+` supports, `-` refutes. **emit** = `code` if a PATTERN_RULE or the hail watch sends it deterministically, `llm` if it is only offered to the specialists' prompt. **flags**: `BIG` weight > 2.5, `DUP` key reused in another condition, `INC` reused with weights 2x or more apart, `DEAD` no agent can emit it. **?** = reviewer verdict.
